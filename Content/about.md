# Hi, I'm Igor.

I lead iOS development at a bank, and I build my own products with AI coding agents. The agents work from specs and tests: I write down what a product must do, they write the code, and the tests decide when it is done.

## What I'm building

- **[RexLab](https://rexlab.enoa.ai)**, a dinosaur learning game for children aged 4 to 7.
- **[FolioTell](https://github.com/igor1309/foliotell)**, an offline iPhone app that reads your notes aloud.
- **[Agister](https://github.com/igor1309/agister)**, a runner for AI-agent work defined in settings files.
- **[Agonara](https://github.com/igor1309/agonara)**, a place to build learning programs with the agent you already use.

Each one is a public repository with its code and tests. The [portfolio](/portfolio) has screenshots and details.
